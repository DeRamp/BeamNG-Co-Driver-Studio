# Co-Driver Studio — architecture contract

Windows desktop tool for recording BeamNG.drive rally co-driver voice packs.
Python 3.13 + PySide6 (Qt Widgets) + numpy + sounddevice + soundfile. NO scipy (keep the
bundle small): filters are FFT-domain or hand-written biquads in numpy.
Shipped as a PyInstaller one-folder build: `CoDriverStudio.exe`, no prerequisites.

Dev env: `.venv\Scripts\python` (already has PySide6-Essentials, numpy, sounddevice,
soundfile, pyinstaller, pytest). Run tests: `.venv\Scripts\python -m pytest -q`.

## Package layout (`codriver_studio/`)

| module | owner | purpose |
|---|---|---|
| `data/phrases_en.json` | done | phrase catalog (generated by `tools/build_catalog.py`, do not hand-edit) |
| `catalog.py` | project agent | load catalogs |
| `dsp.py` | audio agent | trim, effects, resample, file IO — pure numpy, no Qt |
| `audio_io.py` | audio agent | mic recording + playback via sounddevice — no Qt |
| `project.py` | project agent | project model + persistence — no Qt |
| `exporter.py` | project agent | builds the BeamNG mod zip — no Qt |
| `sample_calls.py` | project agent | compose full pacenote calls for preview — no Qt |
| `ui/…` | UI agent | all Qt code |
| `__main__.py` | UI agent | entry: `python -m codriver_studio` |

Only `ui/` may import Qt. All audio arrays are `np.float32`, mono, 1-D, range [-1, 1].
Times are seconds (float) unless the name ends in `_ms`.

## BeamNG format (verified against the game install + a community mod)

Mod zip root contains:
```
lua/ge/extensions/gameplay/rally/compositors/voicepacks/<dirname>/voicepack.json
lua/ge/extensions/gameplay/rally/compositors/voicepacks/<dirname>/metadata.json
lua/ge/extensions/gameplay/rally/compositors/voicepacks/<dirname>/audio/pacenote_*.ogg
lua/ge/extensions/gameplay/rally/compositors/voicepacks/<dirname_casual>/voicepack.json   (reuseAudioFrom: [<dirname>])
```
(No translation json — persona is written as literal text; language/dialect keys already exist in the game.)
- Regular phrase filename: `pacenote_<hash>.ogg`, hash = lower, drop `'`, non `[a-z0-9]` → `_`,
  collapse `_`, strip `_`. Already precomputed as `file_stem` in the catalog.
- Takes / variants (regular phrases): game picks randomly among `<stem>.ogg`, `<stem>_1.ogg`,
  `<stem>_2.ogg`, … that are listed in metadata.json. Export rule: 1 enabled take → `<stem>.ogg`;
  N>1 enabled takes → `<stem>_1.ogg … <stem>_N.ogg`.
- Single-take phrases (`single_take == true`: all `system` phrases plus the two fixed "over crest" slots
  `pacenote_over_crest_1` (crest modifier) / `pacenote_over_crest_2` (corner shape)): the game requests a fixed
  file name → exactly ONE take is exported as `<file_stem>.ogg`: the first enabled take. Enabling a take of a
  single-take phrase disables its siblings. Phrases may carry a `hint` (display-only, e.g. which "over crest").
- metadata.json: `{ "<basename>.ogg": {"audioLen": <seconds float, 6 dp>, "sha1": sha1(utf8 spoken text), "audioSha1": sha1(file bytes)} }`.
  The game only reads `audioLen`: the queue advances at audioLen+gap AND force-stops the clip at audioLen+0.25 s,
  so it MUST be measured from the encoded .ogg after writing (`soundfile.info(path).frames / samplerate`).
  Every exported ogg needs an entry (unlisted files are never candidates).
- voicepack.json (enthusiast):
  `{"persona", "language", "dialect", "compositorStyle": "english/enthusiast", "notebooks": ["enthusiast","structured"],
    "styleLabel": "ui.options.rally.styles.enthusiast.name", "styleDetailLevel": 50, "enableSpeedScaling": true,
    "codriverTimingOffsetSeconds": 0.0, "scriptHash": <catalog source_script_hash>,
    "linkWordGapMs", "cornerGapMs", "phraseGapMs", "pacenoteGapMs"}`
  casual: compositorStyle `english/casual`, notebooks `["casual","structured"]`, styleLabel `...casual.name`,
  styleDetailLevel 10, `reuseAudioFrom: [<enthusiast dirname>]`, no audio dir, no metadata.json.
  Required keys for the game to list a pack: persona, language, styleLabel, notebooks (non-empty); compositorStyle
  must be set too. `persona` is shown RAW in the in-game picker → write the literal display name (NOT a translation
  key). No translation json is needed (language/dialect keys already exist in the game). scriptHash/sha1 are never read.
- dirname = the pack's global identity in the shared virtual FS (two mods with the same dirname merge!). Generate ONCE
  at project creation: `<slug>_<yyyy-mm-dd>_<6 random hex>` (casual: `<slug>_casual_<yyyy-mm-dd>_<same hex>`), store
  in project.json, never regenerate (the in-game selection is remembered by dirname). Slug `[a-z0-9_]`, no leading `_`.
- The game caches the voicepack index + metadata for the whole session → after export the user must restart
  BeamNG (or Ctrl+L Lua reload). UI must say so; warn if `BeamNG.drive.x64.exe` is running. Overwriting the zip while
  the game runs may fail (PermissionError) → friendly message.
- Gaps (audioManager.lua / compositorUtil.lua): linkWordGapMs after "into"/"and"; cornerGapMs between the clips
  making up one corner call (call → length → shape); phraseGapMs between all other clips within a note;
  pacenoteGapMs after the last clip of a note. Negative gap = next clip starts early, previous keeps playing
  (plain MIX overlap, no crossfade); minimum step 0.01 s. Clamps: corner/phrase/link -200..200, pacenote -100..400 ms.
  In-game note order: `[into|and] corner [length] [shape] [modifiers...] [distance]` — distance ENDS a note.
- Countdown clips (`countdown*`, `countdowngo`) are queued 1/s → exporter warns if any is ≥ 0.9 s.
- Loudness of official packs: RMS ≈ -24 dBFS (range -26.6..-21.4), peaks -3.5..-8 dBFS. Normalize to
  `target_rms_db=-23` with a `peak_ceiling_db=-3` limit, not to a -1 dBFS peak.
- Missing phrases: silent in game (no fallback). Do NOT use reuseAudioFrom to fill gaps from official packs (it mixes voices).
- English language key: `ui.options.rally.languages.english.name`, dialects `ui.options.rally.dialects.en-US.name` / `en-GB`.
- Export audio: mono OGG Vorbis, default 48000 Hz (official packs are all 48 kHz mono; rate is not checked by the game).
- User mods folder: `%LOCALAPPDATA%\BeamNG\BeamNG.drive\current\mods\`.

## Catalog (`data/phrases_en.json`)
```json
{"language":"en","language_label":"English","source_script_hash":"1b10…","categories":[…],
 "phrases":[{"id":"hard_left","text":"hard left","category":"corners","file_stem":"pacenote_hard_left",
             "system_key":null,"system_variant":null,"single_take":false,"hint":null}, …]}
```
`id` is stable and language-independent — it is the key everywhere. Translations later: a project
may carry `translations: {phrase_id: "spoken text"}`; the UI shows the translation as the line to
read, falling back to catalog `text`. File names never change with translation.

### dsp.py
```python
def read_audio(path) -> tuple[np.ndarray, int]          # any soundfile format, mixed down to mono float32
def write_wav(path, x, sr)                              # PCM_24 (lossless raw takes)
def write_ogg(path, x, sr, quality=0.6)                 # Vorbis

def measure_noise_floor_db(x, sr) -> float
def auto_trim(x, sr, sensitivity=0.5, pre_pad_ms=40, post_pad_ms=80) -> tuple[float, float]
    # (start_s, end_s) of speech incl. padding, clamped to [0, len/sr]. sensitivity 0..1 (higher = keeps quieter sounds).
    # Robust to: room noise, mouth clicks/desk thumps (<~40 ms isolated bursts), breaths, gaps between words
    # ("one point five km" must stay ONE region). No speech found → (0, len/sr).
class LiveSilenceDetector:   # hands-free mode
    def __init__(self, sr, silence_ms=700, sensitivity=0.5, ignore_initial_ms=250, min_speech_ms=130)
        # arms only on >= min_speech_ms of sustained voiced speech; nothing in the first ignore_initial_ms (keypress)
    def feed(self, block: np.ndarray) -> bool           # True once speech has started AND been followed by silence_ms of silence
    def reset(self)
@dataclass class EffectSettings:   # all fields JSON-serialisable; defaults = "Clean" (only normalize on)
    enabled: bool; highpass_hz; lowpass_hz; drive (0..1 saturation); bitcrush_bits (0=off); compression (0..1);
    noise_db (None/-inf = off, else dBFS of hiss bed); squelch (bool, click+short noise burst at start/end);
    squelch_db; normalize (bool, default True); target_rms_db=-23.0; peak_ceiling_db=-3.0; gain_db; reverb/“helmet” small room (0..1) optional
    def to_dict(self) -> dict; @classmethod from_dict(d) -> EffectSettings   # tolerant of missing/extra keys
PRESETS: dict[str, EffectSettings]   # "Clean", "Helmet Intercom", "Rally Radio", "Old CB", "Walkie-Talkie"
def apply_effects(x, sr, settings, seed=0) -> np.ndarray     # deterministic for a given seed
def render_take(x, sr, trim_start, trim_end, settings, out_sr=48000, fade_ms=8, seed=0) -> np.ndarray
    # crop → short fade in/out → effects → RMS normalize w/ peak ceiling → resample to out_sr → final peak safety
def peaks_for_display(x, n_buckets) -> tuple[np.ndarray, np.ndarray]   # (mins, maxs) for waveform drawing
```

### project.py
Project = folder: `project.json` + `takes/<phrase_id>/take_###.wav` (raw, untrimmed, device rate).
```python
@dataclass class Take: file (relative posix path); trim_start; trim_end; enabled=True; auto_trimmed=True; created (iso str); duration (raw seconds)
@dataclass class PackInfo: persona="My Co-Driver"; author=""; language="english" (builtin id english/spanish → game key, else literal); dialect="en-US" ("" = omitted); dirname (generated once, see format notes);
    version="1.0"; export_sample_rate=48000; link_word_gap_ms=-40; corner_gap_ms=0; phrase_gap_ms=0; pacenote_gap_ms=100;
    include_casual=True; codriver_timing_offset_s=0.0
class Project:
    @classmethod create(cls, folder, persona, language="en") -> Project
    @classmethod open(cls, folder) -> Project            # tolerant of missing take files (marks them missing, never crashes)
    folder: Path; catalog: Catalog; pack: PackInfo; effects: dsp.EffectSettings; trim_sensitivity: float
    translations: dict[str, str]
    def spoken_text(self, phrase_id) -> str
    def takes(self, phrase_id) -> list[Take]
    def add_take(self, phrase_id, x, sr, auto_trim=True) -> Take    # writes wav, runs dsp.auto_trim, saves
    def delete_take(self, phrase_id, take_index)                    # deletes file too
    def set_take_enabled(self, phrase_id, take_index, enabled)      # single_take phrases: enabling one disables siblings

    def reauto_trim(self, phrase_id, take_index, sensitivity=None)

    def render_take(self, phrase_id, take_index, out_sr=None) -> tuple[np.ndarray, int]   # trimmed+effects
    def status(self, phrase_id) -> str                  # "missing" | "recorded" | "disabled" (takes exist but none enabled)

    def save(self)                                      # atomic write (tmp + replace)
```

### UI (`ui/`)
Main window, dark theme. Tabs/pages: **Phrases** (table grouped by category, status, takes,
play, filter, progress), **Record** (guided mode: big current text, next preview, Space record/stop,
Enter keep, R retake, ←/→ navigate, hands-free toggle, level meter, device picker), **Trim editor**
(waveform with draggable in/out handles, play trimmed/full, nudge, zoom, re-auto-trim w/ sensitivity,
per-take enable checkbox), **Effects** (preset combo + sliders, A/B preview on any phrase),
**Sample calls** (type or click to build, play, random stage), **Pack / Export** (pack info, gaps,
export zip, export straight to BeamNG mods folder, missing-phrase warning). Audio work happens off
the GUI thread or is short enough not to stall it. Settings (last project, devices) via QSettings.
